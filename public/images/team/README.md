# Team photos

One photo per staff member. Recommended: portrait orientation, roughly a
4:5 aspect ratio (matches the crop used on the Team section's cards),
at least 800px wide.

Name each file after the person, lowercase and hyphenated —
e.g. `alhaji-kamara.jpg`. To use one, update that person's `image` field
in `src/sections/Team.jsx` to `/images/team/<filename>`.
