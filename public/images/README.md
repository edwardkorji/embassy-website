# Images

Local image assets for the site, organized by where they're used. Anything
placed here is served directly at the matching URL path — a file at
`public/images/team/ambassador.jpg` is reachable at `/images/team/ambassador.jpg`.

- `team/` — staff photos, one per person
- `hero/` — background photo(s) for the homepage hero section
- `gallery/` — general embassy/event photos (for a future gallery section)

See the README inside each folder for naming conventions, recommended
sizes, and which file in the code to point at a new image.
